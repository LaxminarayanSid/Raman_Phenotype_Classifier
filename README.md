# Raman_Phenotype_Classifier

This is the code used to generate the results and the images shown in the manuscript *An interpretable machine learning analysis of phenotype-sensitive Raman spectra for lignocellulosic biovalorization-relevant bacteria*.

The data are 360 bulk Raman spectra of *Pseudomonas putida* (`PP`) and *Corynebacterium glutamicum* (`CBG`) grown with 0 mM (`A`) or 20 mM (`C`) benzoate and sampled at 5, 24 and 48 h (3 biological replicates x 10 spectra per sample). The notebooks preprocess the spectra, train classifiers for species, benzoate stress and culture age, and explain the ANN decisions with saliency analysis.

## Notebooks

Run them in this order (each one reads files written by the earlier ones).

| Notebook | What it does |
|---|---|
| `Raw_Dataset_Compilation.ipynb` | Reads the raw Renishaw `.txt` exports, shifts each spectrum's wavenumber axis to the 520.5 cm<sup>-1</sup> silicon external standard and keeps the integer wavenumbers common to all files. It writes the compiled table `Raw_Raman_Dataset_2025.xlsx`. |
| `Data_Preprocessing_Pipeline.ipynb` | Applies the preprocessing pipeline (silicon intensity normalization, cosmic-ray removal, baseline subtraction, Savitzky-Golay smoothing, 400-1800 cm<sup>-1</sup> truncation) to every spectrum. It writes `Preprocessed_Raman_Spectra_2025.pkl` and Figure 1. |
| `PCA_Qualitative_Analysis.ipynb` | Runs an exploratory PCA on the full dataset and plots the PC1/PC2 scores by species, benzoate condition and culture age together with the OD<sub>600</sub> growth curves and PC loadings. It produces Figure 2 and Figure S1. |
| `LinearSVC_HypTune.ipynb` | Tunes and evaluates linear support vector classifiers on the full z-scored spectra with nested cross-validation (outer loop = leave one biological replicate out). It saves `Performance_SVC_nCV.pkl`. |
| `LinearSVC_PCA_HypTune.ipynb` | Does the same nested cross-validation for linear SVCs trained on the first 6 to 92 principal components (even numbers), refitting the scaler and PCA inside every fold. It saves `Performance_SVC_PCA_nCV.pkl`. |
| `ANN_HypTune.ipynb` | Tunes and evaluates `MLPClassifier` neural networks on the full z-scored spectra with the same nested cross-validation, over activation, hidden layer sizes, alpha and batch size. It saves `Performance_ANN_nCV.pkl`. |
| `ANN_PCA_HypTune.ipynb` | Tunes and evaluates the ANNs on the first 6 to 92 principal components, again refitting the scaler and PCA within each fold. It saves `Performance_ANN_PCA_nCV.pkl`, which also holds the fitted PCA objects used for interpretation. |
| `ML_Performance_Comparison.ipynb` | Loads the four performance dictionaries and compares ANN and SVC accuracy against the number of PCs and the full-spectrum models, then shows the 24-PC ANN confusion matrices and where its errors fall. It produces Figures 3, 4 and 5. |
| `Interpretability_Analysis.ipynb` | Converts the selected 24-PC ANNs to PyTorch, computes Captum saliency scores per PC, back-projects them onto wavenumbers through each fold's PCA loadings and flags the most influential regions (z-score >= 2.5). It produces Figures 6 to 8 and Figures S2 to S4. |

## Folders and data files

| Path | Contents |
|---|---|
| `Raw Raman Data/` | Raw spectrometer exports, one subfolder per collection day (`05_06_2025` to `05_09_2025`): sample spectra as `.txt` (and Renishaw `.wdf`) files, plus the `Standard_785*` silicon standard scans used for drift correction. Sample files are named `<species>_cell_<condition><replicate>_<age in h>`, e.g. `PP_cell_A1_24`; a `-1` suffix marks the second file of the same sample. |
| `Performance Dictionaries/` | Pickled nested cross-validation results written by the four tuning notebooks (`Performance_ANN_nCV.pkl`, `Performance_ANN_PCA_nCV.pkl`, `Performance_SVC_nCV.pkl`, `Performance_SVC_PCA_nCV.pkl`). Each holds, per fold and task, the train/test data, predictions, grid-search object, best model, confusion matrix and classification report. |
| `Paper and SI images/` | Figures generated by the notebooks: `Figure_1` to `Figure_8` for the main text and `Figure_S1` to `Figure_S4` for the supplementary information. |
| repository root | `Raw_Raman_Dataset_2025.xlsx` (compiled raw spectra), `Preprocessed_Raman_Spectra_2025.pkl` (preprocessed spectra, wavenumbers, labels and replicate IDs) and `OD_data.pkl` (OD<sub>600</sub> growth curves at 0 and 20 mM benzoate). |

`Performance_ANN_PCA_nCV.pkl` (about 140 MB) is stored with [Git LFS](https://git-lfs.github.com). Run `git lfs install` before cloning, or `git lfs pull` afterwards, to download it.

## Requirements

Python 3.11 (the notebooks were run on 3.11.7). Install with `pip` (or `conda`); versions are listed where they could be determined from the repository.

| Package | Version | Used for |
|---|---|---|
| numpy | 1.x (the pickles reference `numpy.core`, so not 2.x) | arrays |
| pandas | 2.x (a compatibility line re-adds `DataFrame.iteritems`) | reading/writing the data table |
| scipy | not recorded | Savitzky-Golay filter |
| scikit-learn | 1.2.2 (version stored in the saved models) | StandardScaler, PCA, MLPClassifier, SVC, cross-validation |
| matplotlib | 3.7 or 3.8 (the notebooks call `cm.get_cmap`, removed in 3.9) | figures |
| matplotlib-venn | not recorded | Venn diagram (Figure 8) |
| plotly | not recorded | imported in several notebooks |
| openpyxl | not recorded | `pandas.read_excel` / `to_excel` for the `.xlsx` file |
| BaselineRemoval | not recorded | baseline subtraction |
| orpl | not recorded | cosmic-ray removal (`crfilter_single`) |
| pyDOE | not recorded | imported in `Data_Preprocessing_Pipeline.ipynb` |
| torch | not recorded | PyTorch copy of the ANNs |
| captum | not recorded | saliency scores |
| jupyter | not recorded | running the notebooks |

Example (adjust versions as needed):

```bash
pip install "numpy<2" "pandas>=2,<3" scipy scikit-learn==1.2.2 "matplotlib>=3.7,<3.9" matplotlib-venn plotly openpyxl BaselineRemoval orpl pyDOE torch captum jupyter
```

Loading the pickled models requires the same scikit-learn version (1.2.2) that created them.

The notebooks use Windows-style paths (for example `"Performance Dictionaries\\Performance_ANN_nCV.pkl"`), so run them on Windows or change the path separators.
